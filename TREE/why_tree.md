# TREES
non linear structure
have nodes
1. root node
2. children/child node
3. leaf node
4. ancestor
# types of tree
1. full binary tree- either 2 or 0 nodes/children
2. complete BT - all levels are completely filled except last and last level has nodes as left as possible
3. perfect BT- all leaf nodes are at same level
4. balanced BT - height of tree is at max by log2(N) where N is the number of nodes
5. degenerate tree- its a skew tree ( all node have only one child)
# traversal techniques
1. BFS- breath first search
2. DFS-depth first search

# DFS TYPES
1. inorder traversal( left root right)
2. pre-order traversal(root left right)
3. post-order traversal(left right root)
# BFS
breath wise sorting
right nodes from left to right each node
